# 伝令（Spring Boot起動 + API仕様取得）

フロントエンド開発に必要なバックエンドサーバーを起動し、OpenAPI仕様（swagger.json）を取得する。
**使い方**: `/陣立て` の後に `/伝令` を実行。この2つでフロントエンド開発の準備が整う。

## 前提条件

- `/陣立て` 済みであること（Docker + ビルド確認が完了している状態）

## 手順

### 1. Spring Boot 起動（既存プロセス確認）

まず 8080 ポートで既に起動していないか確認する:

```bash
if curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/v3/api-docs 2>/dev/null | grep -q "200"; then
  echo "Spring Boot は既に起動中です。swagger.json 取得に進みます。"
fi
```

起動していない場合は正系ランチャーで起動する（**Windows 側で `gradlew bootRun` を直接叩かない** — 0xC0000005 クラッシュ・二重起動の温床。正系は vbs→ps1→WSL backend-loop.sh）:

```powershell
Start-Process -FilePath "wscript.exe" -ArgumentList "C:\Claude\mannschaft\start-backend.vbs" -WindowStyle Hidden
```

起動完了を待機（最大90秒）:

```bash
echo "Spring Boot 起動待機中..."
for i in $(seq 1 90); do
  if curl -s -o /dev/null -w "%{http_code}" http://localhost:8080/v3/api-docs 2>/dev/null | grep -q "200"; then
    echo "起動確認 (${i}秒)"
    break
  fi
  sleep 1
  if [ "$i" -eq 90 ]; then
    echo "ERROR: 90秒以内に起動しませんでした"
    exit 1
  fi
done
```

### 2. swagger.json 取得

`docs/openapi.json` に出力する（`frontend/package.json` の `generate:types` が `../docs/openapi.json` を入力とする正本パス）:

```bash
curl -s http://localhost:8080/v3/api-docs -o "${CLAUDE_PROJECT_DIR}/docs/openapi.json"
echo "swagger.json → docs/openapi.json"
```

取得内容を検証:

```bash
if [ -s "${CLAUDE_PROJECT_DIR}/docs/openapi.json" ] && grep -q '"openapi"' "${CLAUDE_PROJECT_DIR}/docs/openapi.json"; then
  echo "検証OK: OpenAPI仕様を正常に取得"
  PATHS=$(grep -c '"/' "${CLAUDE_PROJECT_DIR}/docs/openapi.json" || echo "0")
  echo "パス数（概算）: ${PATHS}"
else
  echo "ERROR: docs/openapi.json の取得に失敗しました"
fi
```

### 3. 結果報告

**Spring Boot は停止しない**。フロントエンド開発中のAPI通信に必要なため、起動したまま維持する。

| 項目 | 状態 |
|------|------|
| Spring Boot 起動 | ✅ / ❌ |
| swagger.json 取得 | ✅ / ❌ |

全て ✅ なら「**伝令完了。バックエンド稼働中、API仕様をフロントエンド陣営に届けました。**」と報告する。
❌ がある場合は原因を調査し、対処方法を提示する。

## 検証・E2E 用 worktree で起動する場合（ポート 8081）

本陣の Spring Boot（8080）と並行で、検証・E2E 用に**本陣と別 worktree** で起動するときは、衝突を避けるため **BE を 8081 固定**で起動する（FE は `/陣触れ` を 3001 で起動。CLAUDE.md「常駐サーバーのポート規約」参照）:

```bash
cd <worktreeのbackend> && ./gradlew bootRun --args='--server.port=8081' &
# 起動確認・swagger 取得は 8081 に読み替える
curl -s http://localhost:8081/v3/api-docs -o "${CLAUDE_PROJECT_DIR}/docs/openapi.json"
```

※ swagger.json（`docs/openapi.json`）は本陣・検証用のどちらから取っても内容は同じ正本なので、上書き先は通常どおり `docs/openapi.json` でよい。

## 備考

- Spring Boot の停止は `/撤収` で Docker と一緒に行う
- swagger.json の再取得だけしたい場合（APIを変更した後など）は、Spring Boot が既に起動中ならステップ2のみ実行される
