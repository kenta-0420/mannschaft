# 撤収（開発環境シャットダウン）

> このスキルは運用作業のため `model: sonnet` 指定（殿のOpus/Fable温存・feedback_opus_infra_ops_danger）。

以下の手順を順番に実行し、開発環境を安全に終了してください。

## 1. Spring Boot 停止（自動再起動ループも含む）

停止フラグを作成してから Java プロセスを強制終了する。
フラグにより自動再起動ループ（正系: `start-backend.vbs` → `start-backend.ps1` → WSL `backend-loop.sh` の連鎖）が次の再起動をスキップして終了する。

```powershell
# 停止フラグ作成
New-Item -ItemType File -Path "C:\Claude\mannschaft\.stop-backend" -Force | Out-Null
Write-Host "停止フラグを作成しました"

# 8080番ポートを使用している Java プロセスを停止
$conn = Get-NetTCPConnection -LocalPort 8080 -ErrorAction SilentlyContinue | Select-Object -First 1
if ($conn) {
    Stop-Process -Id $conn.OwningProcess -Force -ErrorAction SilentlyContinue
    Write-Host "Spring Boot を停止しました (PID: $($conn.OwningProcess))"
} else {
    Write-Host "Spring Boot は起動していません（スキップ）"
}
```

## 1-2. Nuxt 停止（起動中の場合）

```bash
NUXT_PID=$(lsof -ti:3000 2>/dev/null || true)
if [ -n "$NUXT_PID" ]; then
  kill $NUXT_PID 2>/dev/null && echo "Nuxt を停止しました (PID: $NUXT_PID)"
else
  echo "Nuxt は起動していません（スキップ）"
fi
```

## 2. Docker コンテナ停止

```bash
wsl -d Ubuntu-24.04 -- bash -c "cd /mnt/c/Claude/mannschaft && docker compose stop"
```

## 3. WSL2 シャットダウン

```bash
wsl --shutdown
```

## 4. 停止確認

WSL2 が停止していることを確認する。

```bash
wsl --list --running
```

「実行中のディストリビューションはありません。」と表示されれば成功。

## 5. 結果報告

全ステップの結果を以下の形式で簡潔に報告する：

| 項目 | 状態 |
|------|------|
| Spring Boot停止 | ✅ / ⏭️（未起動） |
| Docker停止 | ✅ / ❌ |
| WSL2停止 | ✅ / ❌ |

全て ✅ なら「**撤収完了。お疲れさまでございました。**」と報告する。
