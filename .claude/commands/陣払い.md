# 陣払い（足軽 worktree の安全な撤収）

`.claude/worktrees/agent-*` だけを対象に、単一の実行スクリプトで棚卸しする。既定は **dry-run** であり、実際の撤去は殿が明示した `--apply` のときだけ行う。

```powershell
cd C:\Claude\mannschaft
node scripts/worktree-cleanup.mjs --days 7
node scripts/worktree-cleanup.mjs --days 7 --apply
```

## 安全契約

- 対象は `.claude/worktrees/agent-*` のみ。`feature/*`、非agent worktree、本陣は削除しない。
- `--apply` で撤去できるのは、期限超過かつ clean で、branch が `worktree-agent-*` のものだけ。
- dirty、`git worktree lock`、`index.lock` 検出、実行中が疑われるものは理由を出して保持する。`index.lock` はスクリプトが削除しない。
- missing/prunable は `git worktree prune` で登録だけを整理する。未登録ディレクトリは自動削除しない。
- junction/シンボリックリンクは必ずリンクだけを先に外す。リンク先や本陣の `node_modules` を巻き込まない。

結果には対象数・削除数・保持数・残存 stale 数・失敗理由が出る。終了ゲートには次を用いる。

```powershell
node scripts/worktree-cleanup.mjs --days 1 --check --limit 60
```

総 worktree が 60 本超、または stale が残れば非0で終了する。dirty/locked 等の理由を解消せずに完了扱いにはしない。
