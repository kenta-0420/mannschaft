# 役割分担（モデル呼称とタスク別モデル振り分け）

> このスキル自体は参照用のため `model: haiku`（呼び出しても軽量に終わらせる）。

大名システムでモデルを使い分ける際の**共通呼称**と**振り分け基準**を定義する。Codex 側に作成済みの同名スキルと対になるもの。以後、殿・家老・足軽の起用や `Agent`/`Workflow` の `model` パラメータを相談する際は、この呼称で会話してよい。

## 呼称対応表

| 呼称 | 実体（Claude Code） | 得意分野 |
|---|---|---|
| **Sola** | Opus | 深い思考・設計判断・敵対的検証（意見が割れる/解釈が要る判断） |
| **Terra** | Sonnet | 実装・テスト・調査・インフラ操作（既定・量産の主力） |
| **Lunna** | Haiku | 定型作業・単純grep/置換・索敵・列挙（雑務） |

Fable 5 は殿がこのモデルで動いている場合のみ登場する特別枠（呼称なし）。殿の采配・裁定・最終検分の裏取りに限定し、足軽へは通常継承しない。詳細・時限ルールの経緯はメモリ `feedback_model_routing` を参照。

## 振り分け方針（現行・2026-09-01時点の御下命を反映）

**既定は Terra（Sonnet）。Sola（Opus）は「Terra で実際に詰まった／判断が割れた」場合の格上げ先とし、着手時点での予防的な格上げはしない。**

| タスクの性質 | 既定呼称 | 補足 |
|---|---|---|
| 絵図（設計書作成・要否精査） | Terra → 詰まったら Sola | 機械的な精査・反映は Terra、解釈が割れる箇所のみ Sola |
| 検分（コードレビュー） | **Codex 既定**（Claude 側で回す場合は Terra、敵対的検証ステージのみ Sola） | 2026-09-01 御下命でFable/Opus検分は使わない方針 |
| 軍議（設計・タスク分解） | Terra（偵察・列挙）／Sola（設計判断・トレードオフ精査） | 家老 Plan/Explore も model 省略禁止・明示必須 |
| コーディング・実装全般（FE/BE） | **Terra** | 認可・DB(Flyway)・複雑な型でも着手時は Terra、差し戻された箇所だけ Sola |
| テスト・E2E・ビルド確認 | **Terra** | |
| インフラ操作・プロセス起動停止・環境確認 | **Terra**（Sola/Fable には絶対させない） | Sola は「まず深く理解しろ」バイアスで運用タスクを壊す実績あり |
| 単純grep/置換・ファイル列挙・定型雑務・索敵 | **Lunna** | |

## 使い方

- 殿からサブエージェントを起動する指示や会話の中で「Terra で出陣させて」「ここは Sola に上げる」のように呼称だけで会話してよい。実際の `Agent`/`Workflow` 呼び出しでは呼称を `model` パラメータ（`opus`/`sonnet`/`haiku`）に変換して明示すること（省略禁止）。
- 呼称と振り分け基準そのものの変更履歴・実測値（Opus乱用時のトークン消費など）は `feedback_model_routing` メモリが正本。本スキルは呼称の対応表として同期を保つのみで、判断根拠の詳細はメモリ側を参照する。
