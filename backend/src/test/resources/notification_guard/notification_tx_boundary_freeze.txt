# キーの書式（行番号は含めない。無関係な編集で削除＋追加に見えるのを防ぐため）:
#   <完全修飾クラス名>#<メソッド名> -> <種別>
#
# 種別:
#   ASYNC_SELF_INVOCATION  @Async メソッドの同一クラス内無修飾呼び出し（プロキシを経ず失効）
#   PLAIN_EVENT_LISTENER   通知を発火するリスナーが素の @EventListener（業務コミット前に走る）
#   DIRECT_RUNNER_CALL     sendOne を許可された入口以外から直接呼んでいる
#   ASYNC_WITHOUT_EXECUTOR 通知発火クラスの @Async が executor 無指定（event-pool へ載る）
#   TX_NOTIFY_IN_TRY       @Transactional 文脈で通知を発火し try で失敗を握っている
#   TX_NOTIFY_BARE         @Transactional 文脈で通知を発火している（try 無しの単発）
#   TX_NOTIFY_VIA_DELEGATE @Transactional 文脈から別 Bean へ委譲し、その先で通知が発火する（Issue #3039）
#
# 契約: 付随通知は業務TX内ではイベント発行だけを行う。実通知は明示的な AFTER_COMMIT 境界の後、
#       または項目TX完了を待つ非トランザクションのバッチオーケストレータからのみ実行する。
#       @Async / REQUIRES_NEW / NOT_SUPPORTED 単独は AFTER_COMMIT の代用とみなさない。
#
# 増加は常に CI fail。減少は該当実装差分と同じPRでのみ許可（是正したら必ずこの行を削る）。
# 最終目標は baseline ゼロ。
