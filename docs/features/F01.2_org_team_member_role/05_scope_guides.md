# チーム・組織の案内ページと初回権限設定

## 目的と入口

- `/teams/{slug}/guide` はチームの活動向け機能と利用条件を説明する。
- `/organizations/{slug}/guide` は組織全体の運営向け機能と利用条件を説明する。
- 両ページを各スコープのサイドバー「設定」から `MEMBER` 以上が開ける。管理者向けの権限設定画面とは別の常設入口とする。
- チームと組織では利用可能な機能が異なるため、各ページは対象スコープの機能カタログ API を読み、利用可能な選択式機能・有効状態・有料要否を表示する。カタログの取得にはスコープ所属が必要で、直 URL でも未所属者には内容を表示しない。

## 料金とストレージ

- 無料プランの選択式機能数上限と現在の有効数は各カタログの `planLimit` / `enabledCount` を正とする。基本機能は選択式機能数に含めない。
- 有料機能は `requiresPaidPlan` で表示し、最新の条件・価格はスコープ文脈付きの `/billing/plans` に案内する。価格を案内文へ固定しない。
- ストレージは `/api/v1/me/storage/usage` から対象スコープの使用量・契約に含まれる容量・最大容量（設定がある場合）を表示する。組織とチームは独立の容量枠を持つ。詳細は `/settings/storage` に案内する。容量を取得できなくても機能案内は利用可能とする。

## 初回の MEMBER 既定権限案内

- 対象スコープの実ロールが `ADMIN` で、内部数値 ID が取得でき、既定権限3件すべてが上位設定からの継承である場合に初期設定ダイアログを出す。既存スコープも未設定なら対象とする。
- 予定・ファイル・投稿の管理権限はすべて OFF で始まる。ダイアログでは各権限の意味とトグルを示し、3件を一括保存する。OFF のまま保存すると設定済みになり、再表示しない。
- 「あとで決める」は保存せず、そのブラウザセッション中だけ再表示を抑える。次回セッションでは未設定なら再案内する。常設の権限設定画面からも後で変更できる。
- ダイアログから対象スコープの案内ページへ移動できる。`MEMBER` や `DEPUTY_ADMIN` にダイアログや設定 API を表示しない。
