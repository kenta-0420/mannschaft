## §1 概要 — 将棋との関係・ターン制

囲碁は将棋と**同じターン制（TURN_BASED・コア §D.6）**であり、記録構造（時間/ピリオド無し・スコア連続量無し・勝敗＝勝者＋勝ち方・総手数・局面写真・団体戦の親子ボード）は将棋と共通である。差分は**勝ち方の語彙**（中押し・目数差・反則等）と一部統計・UX ラベルのみ。

`matches.sport='GO'`・`matches.state_model='TURN_BASED'`（導出可）で識別する。

**将棋との主な差分**:

| 観点 | 将棋 | 囲碁 |
|------|------|------|
| 勝ち方 | 投了/詰み/時間切れ/反則勝ち/千日手/持将棋/不戦勝 | 投了（中押し）/目数差勝ち/時間切れ/反則勝ち/不戦勝 |
| 引き分け | 千日手・持将棋で発生 | **持碁（じご・盤面同数）**で発生（コミの有無で稀） |
| 勝敗の量的表現 | 手数のみ | 目数差（`margin`・目数勝ちの場合）を任意保持 |

## §2 event_type カタログ（囲碁）

将棋と**同一のターン制 event_type 集合**を用いる（[05_shogi.md](./05_shogi.md) §2 と同じ）。

```java
// SportEventCatalog の GO 集合（将棋と同一・コア §D.3）
Sport.GO, EnumSet.of(GAME_RESULT, MOVE_COUNT, POSITION_PHOTO, COMMENT, OTHER)
```

### §2.1 出場時間・スコアへの影響（囲碁）

将棋と同一（[05_shogi.md](./05_shogi.md) §2.1）。出場時間（分）概念なし＝`computed_minutes=NULL`・出場時間算出ロジックはターン制で起動しない（コア §D.6）。連続スコアなし＝勝敗は `result`＋勝ち方（§4）。

- **囲碁固有**: 目数勝ちの場合の**目数差（margin）**を任意で保持（`detail JSON` or 専用列＝MVP は `detail` に `{"margin": 5.5}` 等で保持・将棋にはこの概念なし）。中押し勝ち（投了）の場合は margin なし。

## §4 勝敗判定・勝ち方（囲碁）

### §4.1 勝ち方カタログ（`GoWinMethod`）

コア §D.7（ターン制の勝ち方 enum）に対する囲碁の具体値。`matches.win_method` に保持。

```java
// 囲碁固有: 勝ち方（日本棋院の対局規定 標準）
public enum GoWinMethod {
    RESIGNATION,   // 投了（中押し勝ち＝ちゅうおしがち）
    POINTS_WIN,    // 目数差勝ち（盤面の地の差で決着・margin を任意保持）
    TIMEOUT,       // 時間切れ
    FOUL_WIN,      // 反則勝ち（着手禁止点・コウの即取り返し等の反則）
    DEFAULT_WIN    // 不戦勝（相手の不出場）
    // 持碁（引き分け）は result=DRAW で表現（win_method は NULL）
}
```

| 勝ち方 | 説明 |
|--------|------|
| RESIGNATION | 投了（中押し勝ち） |
| POINTS_WIN | 目数差勝ち（margin を任意保持） |
| TIMEOUT | 時間切れ |
| FOUL_WIN | 反則勝ち |
| DEFAULT_WIN | 不戦勝 |

> **保守方針**: 日本棋院の対局規定（出典: <https://www.nihonkiin.or.jp/>）に準拠。実装時に最新規定と照合（本記載は起草時点・唯一の正本は棋院規定）。

### §4.2 勝敗・引き分け

- 勝者 side（HOME=黒 / AWAY=白）を `matches.result` 相当に保持（先手＝黒）。
- **持碁（じご・盤面同数）は引き分け（DRAW）**。コミ（通常 6.5 目）があれば持碁は稀だが、コミ無し対局や特殊ルールで発生し得る。DRAW のとき `win_method` は NULL。
- 目数勝ち（POINTS_WIN）の場合、**目数差（margin）を任意保持**（`detail` に保持・§2.1）。これは統計（平均勝ち目数等）に利用できる。
- 反則は `FOUL_WIN`＋`note`（細分は将来余地・ブロッカーではない）。

### §4.3 団体戦の勝敗導出（親 match）

将棋と完全に同一（[05_shogi.md](./05_shogi.md) §4.3）。団体戦の親 match の勝敗は子ボード（各 1 局）の勝ち星集計から導出（コア §B.6）。`matches.home_score`/`away_score` に勝ち星数を集計。親子ボードの IDOR・テナント検証はコア §C.4。

## §6 統計定義（囲碁固有指標）

### §6.1 個人キャリア統計（`UserMatchStatsResponse`）

将棋（[05_shogi.md](./05_shogi.md) §6.1）と同一の枠組み。囲碁固有の差分:

| 指標 | 算出元（囲碁） |
|------|--------|
| totalGames / wins / losses / draws / winRate | 将棋と同一（持碁＝draw・§4.2） |
| winsByMethod[] | 勝ち方別内訳（投了/目数差/時間切れ/反則勝ち・§4.1） |

| monthlyTrend[] / seasonTrend[] | 月別/シーズン別の対局数・勝率 |

## §8 囲碁固有 UX 細部（ターン制の最小 UI）

将棋（[05_shogi.md](./05_shogi.md) §8）と同一構造。差分のみ:

### §8.1 対局結果記録 UI

- **個人戦（1 局）**: 「対局を記録」→ 黒/白（対戦相手）→ 勝者選択 → **勝ち方選択（投了〔中押し〕/目数差/時間切れ/反則勝ち/不戦勝・§4.1）**→ 目数差勝ちなら**目数（margin）を任意入力**→ 任意で総手数・局面写真・コメント。タイマー・選手グリッド・タイムラインは表示しない。
- **団体戦**: 将棋と同一（各ボード子 match・親勝敗はボード勝ち星から導出・§4.3）。
- **局面写真**: 将棋と同じく既存添付基盤（presign・SVG 除外・サイズ上限・IDOR 逆引き）を流用（コア §B.7・03 §C.7・[05_shogi.md](./05_shogi.md) §8.2）。

### §8.5 ターン制トラッカー（`useMatchTurnTracker`）

将棋と同一の `useMatchTurnTracker`（ターン制専用・コア 04 §G.16）を共用する。状態は `WAITING → IN_PROGRESS → COMPLETED`。手数・勝者・勝ち方・**目数差（囲碁のみ）**・写真・コメントを管理。タイマー無し。

## §9 i18n namespace（囲碁固有ラベル）

| namespace | 囲碁固有の中身 |
|-----------|------------------|
| `match.event_type` | 将棋と同一（GAME_RESULT→「対局結果」等） |
| `match.win_method`（ターン制共通） | RESIGNATION→「投了（中押し）」・POINTS_WIN→「目数差勝ち」・TIMEOUT→「時間切れ」・FOUL_WIN→「反則勝ち」・DEFAULT_WIN→「不戦勝」を 6 言語表示（将棋とキーが一部異なる＝囲碁は POINTS_WIN を持ち千日手/持将棋を持たない・各競技が自競技の勝ち方キーを引く） |
| `match.board`（団体戦共通） | ボード順ラベル（「主将」等・board_number 表示） |

- `match.json` 共通ファイル・`match.win_method.*` はターン制共通 namespace（将棋・囲碁で共有・コア 04 §G.6）。
