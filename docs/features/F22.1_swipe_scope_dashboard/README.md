## 1. 概要

ログイン後のホーム画面を、**個人 / チーム / 組織** の 3 スコープを「横スワイプで循環的に切り替えられる単一ページ」に再構成する機能。
モバイルでは左右フリック、PC では上部セグメントトグル・左右矢印・キーボード（←→）でパネルを切り替える。3 枚のパネルは同時マウントされ、`transform: translateX` でスライドするため**画面の再描画（full re-render）は発生しない**。

本機能は F02.2 マイダッシュボードを**置き換えるものではなく、その上位の「ナビゲーションシェル」**である。各パネルの中身（ウィジェット・データソース・認可）は F02.2 / F02.2.1 を踏襲し、本書ではスコープ切替の操作体系・スコープ選択（タグ）・チーム/組織パネルの厳選ウィジェット構成・新規 API のみを定義する。

> **L1 管理者レンズ（F10.1.1 で追加）**: チーム/組織パネルには、ADMIN / DEPUTY_ADMIN 向けに「メンバー / 管理者」を切り替える**レンズトグル**が追加される（[F10.1.1_team_org_admin_console/02_admin_lens_widgets.md](../F10.1.1_team_org_admin_console/02_admin_lens_widgets.md)）。**横スワイプの軸は「スコープ（個人/チーム/組織）」専用のまま不変**であり、第4タブ『管理』は追加しない。管理者ビューはスコープと直交する「視点」であるため、タブ（同一軸の並び）ではなくトグル（軸への修飾）で表現する。管理者レンズのウィジェット（`ADMIN_*`）の可視性は、メンバー向けの `min_role`（3値）ではなく **`StandardVisibility.ADMINS_AND_ABOVE` をコード固定**でゲートする（F02.2.1 の min_role 管理対象外＝既存 `TEAM_BILLING` 等と同扱い。詳細は [F10.1.1/02 §2.1](../F10.1.1_team_org_admin_console/02_admin_lens_widgets.md)）。

### 1.1 背景

- 現状ダッシュボードは「個人」を起点に、チーム/組織のダッシュボードは個別ページ（`/dashboard/team/{id}` 等）へ遷移して閲覧する設計のため、所属が多いユーザーは「どのスコープを今見ているか」を見失いやすい。
- ADHD 傾向のあるユーザーを含め、「入力摩擦ゼロ・指1本で全スコープを横断」できる回遊体験が求められている（`user_adhd_tendency` 方針）。
- チーム/組織のダッシュボードは F02.2 で多数のウィジェットを定義済みだが、スコープ横断の「ざっと全体を眺める」用途では情報過多。**厳選 8 枚**に絞り、回覧板・アンケート・出席確認を 1 枚の「要対応」ウィジェットに集約することで、見るべきものを瞬時に把握できるようにする。

### 1.2 目的 / コンセプト

| 観点 | 内容 |
|------|------|
| 操作 | スワイプ / トグル / 矢印 / キーボードでスコープを循環切替（個人 → チーム → 組織 → 個人 …） |
| 再描画なし | 3 パネル同時マウント + `translateX` スライド。スクロール位置・読み込み済みデータを保持 |
| スコープ選択 | チーム/組織パネル内で、所属する具体的なチーム/組織を「タグ」で選択。表示順をユーザーが設定可、上位 6 件 + ページ送り |
| 厳選ウィジェット | チーム/組織パネルは 8 枚に厳選。回覧板/アンケート/出席確認を統合「要対応」ウィジェットに集約 |
| 検索 | 各パネル右上に「チーム検索」「組織検索」のキーワード入力フォーム。既存検索ページへ遷移 |
| 個人パネル | 既存 `frontend/app/pages/dashboard.vue` をそのまま内包（変更なし） |

## 2. スコープ

### 2.1 対象ロール

| ロール | 個人パネル | チーム/組織パネル |
|--------|:--------:|:----------------:|
| SYSTEM_ADMIN | ✅ | 所属スコープのみタグ表示（全スコープ閲覧は F10.1 管理画面側） |
| ADMIN | ✅ | ✅ 所属スコープ。F02.2.1 のロール別可視性に従う |
| DEPUTY_ADMIN | ✅ | ✅ 所属スコープ。権限グループに応じた可視性 |
| MEMBER | ✅ | ✅ 所属スコープ（`min_role <= MEMBER` のウィジェットのみ） |
| SUPPORTER | ✅ | ✅ 所属スコープ（`min_role <= SUPPORTER` のウィジェットのみ） |
| PUBLIC / 未ログイン | ❌（ログイン必須。本機能はログイン後ホーム） | ❌ |

> 本機能はログイン後のホーム画面であり、未ログイン公開閲覧（F19.1）は対象外。

### 2.2 対象レベル

- [x] 個人 (Personal) — 既存 `dashboard.vue` を内包
- [x] チーム (Team) — 厳選 8 ウィジェット + タグ選択
- [x] 組織 (Organization) — 厳選 8 ウィジェット + タグ選択

### 2.3 スコープ外

| 項目 | 理由・参照先 |
|------|------------|
| 個人パネルのウィジェット構成変更 | 既存 `dashboard.vue` をそのまま内包（変更なし） |
| ウィジェット内データの CRUD | 各機能ドメイン（タイムライン/掲示板/TODO 等）が担当 |
| 課金サマリー等の管理者限定ウィジェット | 厳選 8 枚に**含めない**（F02.2 のチーム/組織ダッシュボード詳細ページで閲覧） |
| 検索フィルタ（地域・テンプレート等） | 既存検索ページ（`/teams/search` 等）が担当。本機能のフォームは**キーワードのみ** |
| 未ログイン公開ページ | F19.1 / F15.4 が担当 |
| スコープフォルダの CRUD | F15.3 が担当。本機能は**読み取り流用**のみ |

### 2.4 関連機能との境界

| 機能 | 関係 |
|------|------|
| F02.2 マイダッシュボード | **母体**。個人パネル = F02.2 個人ダッシュボード。チーム/組織パネルのウィジェットは F02.2 の widget_key・データソースを流用 / 厳選 |
| F02.2.1 ウィジェット可視性 | チーム/組織パネルのウィジェットは `viewerRole` / `min_role` 判定を**そのまま**通す |
| F15.3 スコープフォルダ | タグの**任意フィルタ**として `my_scope_folders` / `my_scope_folder_items` を読み取り流用 |
| F20.1 ナビカスタマイズ | store + plugin（localStorage 楽観更新 + サーバー同期）の**実装手本** |
| [F04.11 統合通知インボックス](../F04.11_notification_inbox/README.md) | **棲み分け**。本機能「要対応」＝スコープ別のアクション抽出ウィジェット／F04.11＝個人横断の全通知の受け皿（スヌーズ/アーカイブ/ラベル）。両者は補完関係で競合しない（F04.11 §7） |
