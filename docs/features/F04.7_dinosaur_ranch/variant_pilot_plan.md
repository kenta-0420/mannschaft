# 恐竜4外見の隔離pilot計画

作成日: 2026-10-22。状態: 軍議案・未承認。対象: アロサウルス1種。実装開始・素材承認・正式公開の記録ではない。既存規約の正本は CLAUDE.md、軍議手順は `.claude/commands/軍議.md`。本書のACは後続の試練・検分・実機証拠へ引き継ぐ。

## 目的と今回の範囲

本人の分身となる恐竜について、現在の基本見た目と4frame歩行を保持し、同一speciesの4外見を見分けられる案を具体化する。最初の成果物は、現在の成体PAINT_2DをV1参照として、V2〜V4の追加静止案を同条件で並べた比較である。追加3案は `staticconcept` の未承認参考画像であり、登録可能なanimation、既存atlasの改版、正式masterではない。

第1段階はアロサウルス成体2D静止のみ。他15種・成長段階の展開、PIXEL化、animation、runtime/catalog接続、DB/API変更を含めない。ユーザーが4外見の方針と実比較を確認した後にのみ、第2段階として同1種のBABY/JUVENILE/ADULT×PIXEL/PAINT_2D×4外見×待機/歩行/食事/喜びを制作・検証する。既存方式と隔離DEV境界を再利用し、必要な変更箇所は承認後の実装計画で特定する。

## 原本と制作方法の制約

第1段階の生成結果は見た目の候補を比べるためだけに使い、その全体画像を既存spriteの置換に使わない。基準bytesとmanifestのハッシュを制作前後に記録する。生成失敗、不要な眼/脚/輪郭の改変、模様の不適合は候補を不採用にして破棄対象へ分け、原本に修復を上書きしない。既存のユーザー資産を削除しない。

第2段階では既存の各stage/style/action/frameを正本とし、体色・模様・腹部等の変更可能部位と、眼/瞳/口/爪/輪郭/脚境界等の保護部位を意味別maskで明示する。mask自体をフレームごとに検分し、単一の色閾値を無検査で全素材へ適用しない。複数部位で同色を使う場合も部位の意味で区別する。体型変更が採択された場合はこの色/模様差方式の適用外として、anchor・足/翼/ひれ・接地の個別調整案を先に提示する。

変更可能mask外の承認済basebytes、frame数/順序、frame寸法、anchor、床位置、phaseStarts、duration、timing、眼と脚の形・位置・可視性、FOODの素材と配置、食事/喜びの演出座標・発火位相を保持する。色/模様は4frame間で追従し、脚の交差や口/眼への侵入、模様の点滅をフレーム単位と再生の両方で検分する。生成画像の揺れ・拡縮だけを動作完成とは扱わない。

## 作業順序と完了判定

1. 本計画とACを軍議検分し、色/模様/体型の未確定を解消する。静止候補は未承認案として先行準備できる。
2. 第1段階の追加3案を比較しVP01〜VP05および適用するVP12/VP15の静的条件を確認する。ユーザーの採否と修正点を記録する。
3. 承認後、意味別maskと4frame保全の試練を先行し、第2段階の24entryへ展開する。runtime接続前に性能予算・具体差分・認可の試験を確定する。
4. VP06〜VP15を検分し、DEV接続を行う場合は実機E2E、その後にアリシゼーションを実施する。実施不能項目は理由と未実施を保持する。
5. 完了証拠は段階別に作る。第1段階は静止比較の完了、第2段階は隔離pilotの完了であり、全64外見・正式診断・本番公開の完了に読み替えない。将来アプリ機能の完了証拠を作る際のscopeは `app` とする。本計画だけで完了証拠や台帳の完了状態を作らない。

今回Entity/Repository、Controller/DTO、正式master登録の部隊は不要。計画・静止候補制作、採否、mask/試練、動画展開、検分/実機の依存順で進める。新台帳行/commit/公開操作は本準備に含めない。
