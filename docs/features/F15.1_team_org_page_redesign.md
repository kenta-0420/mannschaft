# F15.1 チーム・組織ページ全面リデザイン

## 概要

チームページ（`/teams`）と組織ページ（`/organizations`）を、検索メインのUIから「マイチームハブ」「マイ組織ハブ」へ全面リデザインした。

旧来の設計では `/teams` がチーム検索ページとして機能していたが、ユーザーが最もアクセスする「自分の所属チーム」への導線が弱かった。本フェーズでは以下の方針に従いリデザインを実施した。

- **ハブページ（`/teams`, `/organizations`）**: ストアから直接取得した所属チーム/組織一覧 + ウィジェット埋め込み
- **検索ページ（`/teams/search`, `/organizations/search`）**: 既存の検索UIを専用ページに分離

## 実装詳細

### グリッド/リスト切り替え

- `viewMode: 'grid' | 'list'` で管理
- `localStorage` で永続化
  - チーム: キー `mannschaft:teams:viewMode`
  - 組織: キー `mannschaft:orgs:viewMode`
- SSR対応のため `import.meta.client` チェック済み

### WidgetTeamAnnouncements / WidgetOrgAnnouncements の embedded prop

```vue
<WidgetTeamAnnouncements :embedded="true" />
```

- `embedded=false`（デフォルト）: 従来通り `DashboardWidgetCard` ラッパーあり（ダッシュボードページ用）
- `embedded=true`: `DashboardWidgetCard` を外してコンテンツのみ描画（ハブページに直接埋め込み）

### i18nキー

`common.json` の `teamHub` および `orgHub` セクションに追加。
6言語（ja/en/zh/ko/es/de）すべてに対応済み。

### ストアからの直接参照

ハブページではAPIを呼び出さず、Piniaストアの値を直接参照する:
- `teamStore.myTeams`: ログイン時に取得済みの所属チーム一覧
- `orgStore.myOrganizations`: ログイン時に取得済みの所属組織一覧

## Phase 2 への接続点

以下は Phase 2 以降で実装予定:

1. **クイックアクション**: チームカードから直接「掲示板」「チャット」「カレンダー」へのショートカット
2. **未読バッジ**: 各チームの未読通知数をカードに表示
3. **ソート/フィルタ**: 所属チーム一覧のソート（参加日順、アクティビティ順）
4. **ピン留め**: よく使うチームをトップにピン留め
5. **最近アクセス**: 最近見たチームの履歴表示
