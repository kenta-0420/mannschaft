**作成日**: 2026-06-25  
**改訂履歴**:
- v1.0: 初版
- v1.1: 収益モデル（広告・ターゲティング・集計データ）を2度精査して反映
**ステータス**: 御裁可待ち  
**関連機能**: F10.1（管理者変身機能）、アカウント登録フロー

## 1. 概要・背景

### 背景

管理者変身機能（F10.1）の法的根拠を確立するため、以下を整備する。

1. プライバシーポリシーを正式な法的文書として完成させる
2. アカウント登録時にプライバシーポリシーへの同意を取得する
3. 同意記録を DB に保存する（GDPR Art.7 / 個人情報保護法準拠）
4. **広告・ターゲティング・集計データの収益活用を正確に開示する**

### 精査の観点（v1.1 改訂理由）

| 観点 | 発見された問題 | 対応 |
|---|---|---|
| 収益モデル整合 | 広告モジュール（`advertising/campaign`）が存在するのに Cookie は「広告トラッキング不使用」と記載 | 広告利用を正直に開示し、オプトアウトを提供 |
| 地域ターゲティング | 郵便番号による地域ターゲティングの用途が未開示 | 利用目的・広告セクションに明記 |
| 属性ターゲティング | 年齢・スポーツ種別・所属チーム等の属性広告が未開示 | 広告セクションを新設して開示 |
| データ販売の曖昧さ | 「個人情報の販売」と「匿名集計データの外部活用」が区別されていない | 明確に分離して説明 |
| 改正APPI（2022） | 「個人関連情報」の第三者提供規定への言及なし | 専用条項を追加 |
| 未成年者広告 | 18歳未満への広告制限が未記載 | 第13条に追記 |

### 第1条：事業者情報

Mannschaft（以下「当社」）は、お客様の個人情報保護に最大限の努力を払います。本プライバシーポリシー（以下「本ポリシー」）は、当社が提供するチーム管理プラットフォーム「Mannschaft」（以下「本サービス」）における個人情報の取り扱いについて定めるものです。本サービスを利用される際は、本ポリシーへの同意が必要です。

---

### 第2条：収集する個人情報

当社は、以下の個人情報をお客様から収集します。

**アカウント登録情報**
- メールアドレス
- 氏名（姓・名）・表示名（ニックネーム）
- 生年月日（年齢確認および未成年者保護のため）
- 郵便番号・居住国（地域サービス提供および地域ターゲティング広告のため）
- パスワード（bcrypt でハッシュ化して保存。平文では一切保存しません）

**プロフィール・活動情報**
- プロフィール画像・アバター
- 所属チーム・組織・スポーツ種別
- スケジュール・シフト・出欠情報
- メッセージ・コメント等の投稿内容

**システム情報**
- IPアドレス・デバイス情報・ブラウザ情報
- ログイン履歴・操作ログ・閲覧ページ
- Cookie・セッション情報

**決済情報**
- 会費・課金処理は Stripe, Inc. が処理します。当社はカード番号・CVV 等の生の決済情報を保持しません。

---

### 第3条：利用目的

収集した個人情報は、以下の目的のために利用します。

1. 本サービスの提供・運営・維持・改善
2. ユーザー認証およびアカウント管理
3. カスタマーサポート・お問い合わせ対応
4. 重要なお知らせ・サービス更新の通知
5. 法令遵守・不正利用・セキュリティ侵害の防止
6. **広告配信（第4条参照）**: 郵便番号・生年月日・所属属性等を用いた地域・属性ターゲティング広告の配信
7. **集計・分析（第5条参照）**: 個人を特定しない形式での統計分析・サービス改善・事業報告

目的外の利用は行いません。

---

### 第4条：広告配信・ターゲティング

本サービスは、広告収益によって一部の機能を無料提供しています。広告配信に際し、以下の方法でお客様の情報を利用する場合があります。

#### 4-1. ターゲティング広告の種類

| 種類 | 使用するデータ | 例 |
|---|---|---|
| 地域ターゲティング | 郵便番号・都道府県 | 近隣のスポーツ用品店の広告 |
| 属性ターゲティング | 年齢層・スポーツ種別・チーム規模 | スポーツ種別に関連する用品・施設 |
| 文脈ターゲティング | 閲覧中のページ内容 | スケジュールページでのスポーツ関連広告 |

#### 4-2. 当社が行わないこと

- **個人情報の直接販売**: 氏名・メールアドレス・電話番号等の個人を特定できる情報を広告主に販売することは行いません
- **行動プロファイリングの外部提供**: お客様個人の詳細な行動履歴を広告主が直接参照できる形で提供することは行いません
- **センシティブ情報による広告**: 健康情報・宗教・政治的思想等のセンシティブ情報に基づく広告は行いません
- **未成年者へのターゲティング広告**: 18歳未満のユーザーへのターゲティング広告は行いません（第13条参照）

#### 4-3. 広告のオプトアウト

アカウント設定（設定 › プライバシー）からターゲティング広告をオプトアウトできます。オプトアウト後は、属性・地域に依らない一般広告のみが表示されます。文脈ターゲティング（閲覧ページ内容に基づく広告）はオプトアウトできません。

### 第5条：集計データの分析・外部利用

#### 5-1. 集計・匿名化データの活用

当社は、個人を特定できない形式に集計・匿名化したデータを以下の目的で活用することがあります。

- サービス利用動向の分析・機能改善
- 業界レポート・統計資料の作成・公開
- 広告効果の測定・改善
- 投資家・パートナー向けの事業報告

この集計データはいかなる単一個人も特定できない形式で取り扱います。

#### 5-2. 集計データの外部提供

匿名化・集計したデータは、以下の条件を満たす場合に外部のパートナーに提供することがあります。

- 提供先において個人の再識別を行わないことを契約上保証
- 提供目的がスポーツ・コミュニティ分野の研究・統計に限定される
- 個人を特定できる情報が集計データに含まれないことを技術的に検証済み

なお、改正個人情報保護法（2022年）の「個人関連情報」の第三者提供規定に基づき、提供先において個人情報と照合される可能性がある場合は、お客様の同意を取得します。

#### 5-3. 明示的に行わないこと

- **個人情報の販売**: 個人を特定できる情報（氏名・メール・電話番号・正確な位置情報等）を金銭対価と引き換えに第三者に販売することは行いません
- **プロファイルの販売**: 個人を特定できる行動プロファイル・スコアリングデータを販売することは行いません

### 第6条：第三者提供（個人情報）

当社は、第5条の集計データを除き、以下の場合を除いてお客様の個人情報を第三者に提供しません。

- 法令に基づく場合（捜査機関等からの適法な要請）
- お客様または第三者の生命・身体・財産の保護のために必要な場合
- 公衆衛生の向上または児童の健全育成のために必要な場合
- 国の機関または地方公共団体が法令の定める事務を遂行するために必要な場合
- お客様の明示的な同意がある場合

### 第8条：Cookie・アクセスログ

#### 8-1. Cookie の種類

| 種類 | 目的 | 無効化 |
|---|---|---|
| **必須 Cookie** | ログインセッション維持・CSRF対策 | 不可（無効化するとログイン不能）|
| **機能 Cookie** | ダークモード等の表示設定保存 | アカウント設定から管理可能 |
| **広告 Cookie** | ターゲティング広告の頻度制御・効果測定 | アカウント設定（設定 › プライバシー）またはブラウザ設定からオプトアウト可 |

EU・EEA 居住者の方には、初回アクセス時に必須 Cookie 以外の同意を取得します（Cookie 同意バナー）。

#### 8-2. アクセスログ

セキュリティ監視・障害対応のため、IPアドレス・アクセス時刻・操作内容のログを最大 90 日間保存します。

サービス品質の維持・カスタマーサポートの提供・不正利用調査のため、当社の権限を持つシステム管理者がお客様のアカウントに代わって本サービスを操作する場合があります（以下「管理者アクセス」）。

**実施条件**

1. **目的の限定**: カスタマーサポート対応、技術的障害の調査・再現、法令に基づくコンプライアンス確認のみを目的とします。目的外の利用は社内規程で禁止されています。
2. **権限者の限定**: 権限を明示的に付与されたシステム管理者のみが実施できます。
3. **監査ログの保持**: すべての管理者アクセスは、実施者・目的・理由・実施日時を含む監査ログとして記録・一定期間保管されます。
4. **最小限の原則**: 目的達成に必要な最小限の範囲でのみ実施します。

本機能は Zendesk・Shopify 等の主要 SaaS でも採用されている標準的なサポート手法です。

### 第11条：個人情報の開示・訂正・削除の権利

- **確認・訂正**: アカウント設定（/settings/profile）から個人情報を確認・変更できます。
- **データポータビリティ**: アカウント設定からデータのエクスポートをリクエストできます。
- **退会・削除**: 退会申請後、GDPR 第17条に基づき30日以内に個人情報を消去します。法令上の保存義務があるデータ・匿名化済みの集計データは保持する場合があります。
- **広告オプトアウト**: 第4条-3 を参照してください。

EU・EEA 居住者の方は、上記に加えて GDPR 第15〜22条に基づく権利（処理の制限・異議申し立て等）を行使できます。

---

### 第12条：国際データ移転

本サービスは AWS・Cloudflare 等（いずれも米国本社）を利用しているため、お客様の個人情報が日本国外に移転・保管される場合があります。

EU・EEA 居住者の方のデータについては、GDPR 第46条に基づく標準契約条項（SCC）またはその他の適切な保護措置が講じられた上で移転が行われます。

---

### 第13条：未成年者の個人情報

本サービスは、利用規約に基づき18歳以上の方を対象としています。

- 18歳未満のユーザーへのターゲティング広告は一切行いません
- 18歳未満と判明した場合、アカウントを停止し収集した個人情報を速やかに削除します
- 登録時に収集する生年月日は年齢確認のためにのみ使用し、広告ターゲティングには年齢層（例：20代・30代）のみを使用します

- **軽微な変更**は本ページの「最終更新日」を更新することで通知します。
- 改定後に本サービスをご利用いただいた場合、改定後のポリシーに同意したものとみなします。

## 4. DB設計（同意記録）

### Flyway マイグレーション: V131.001

```sql
ALTER TABLE users
    ADD COLUMN privacy_policy_accepted_at DATETIME NULL COMMENT '同意日時（NULL=未同意または旧登録）' AFTER deleted_at,
    ADD COLUMN privacy_policy_version     VARCHAR(20) NULL COMMENT '同意時のポリシーバージョン'       AFTER privacy_policy_accepted_at;
```

> **なぜ別テーブルでなくカラムか**: 現フェーズは「登録時に最新版へ同意」のシンプルなモデル。複数バージョン履歴管理が必要になった場合は別テーブルに移行する（現行バージョンは 1.1.0）。

## 5. BE設計

### RegisterRequest 追加フィールド

```java
@AssertTrue(message = "AUTH_PP_001")
private boolean privacyPolicyAccepted;

@NotBlank(message = "AUTH_PP_002")
private String privacyPolicyVersion;
```

### AuthRegistrationService 変更

登録成功後、同意情報を記録する。

```java
user.setPrivacyPolicyAcceptedAt(LocalDateTime.now());
user.setPrivacyPolicyVersion(request.getPrivacyPolicyVersion());
```

### エラーコード

| コード | 条件 | HTTP |
|---|---|---|
| AUTH_PP_001 | `privacyPolicyAccepted` が false | 400 |

## 8. 受け入れ条件（AC）

| AC# | 条件 | テスト種 |
|---|---|---|
| AC-1 | `privacyPolicyAccepted=false` で登録APIを叩くと400（AUTH_PP_001） | API契約テスト |

## 9. 残課題（別フェーズ）

| 課題 | 概要 |
|---|---|
| Cookie 同意バナー（GDPR対応） | EU/EEA ユーザーへの初回 Cookie 同意取得 |
| 既存ユーザーへのポリシー更新通知 | 次回ログイン時バナー＋再同意フロー |
| 広告オプトアウト UI | 設定 › プライバシーページの新設 |
| 管理者変身機能の監査ログ強化 | 目的・理由入力 + DBテーブル（F10.1-phase2） |
| 専門翻訳レビュー | 法的文書は機械翻訳のみに頼らず専門家レビュー推奨 |
| 利用規約（terms.vue）の同様対応 | 登録時同意チェックへの追加 |
