## 1. 画面一覧

| # | 画面 | パス | 主対象 |
|---|---|---|---|
| B-1 | マイベータ特典 | `/settings/billing` 内セクション（F20.1 U-5 に同居） | 本人 |

> 専用ページを増やさない（ADHD 原則: 入口を散らさない）。特典は課金管理画面の 1 セクションとして表示する。

### B-1 マイベータ特典

- **特典カード**: フェーズバッジ（「ベータ第 2 期」）・付与日・対象機能リスト（折りたたみ・段階開示）・期間表示は **「サービス提供期間中無償」固定文言**（`validUntil=null` のとき。**「永久」の語を出さない**・03 §8）。
- **充足進捗**（未付与のとき・`eligibility` から描画）: メトリクスごとのプログレスバー（「アクティブ日数 9/14 日」）。達成見込みを可視化する ADHD フレンドリーな進捗開示。**進捗はモチベーション表示であり、付与は自動バッチが行う旨を明記**（申請ボタンは置かない）。
- **称号バッジ**: 付与済みなら `BETA_TESTER` バッジ（F04.7 の既存バッジ表示コンポーネントを流用・新規コンポーネントを作らない）。

### B-2 チーム/組織のベータ特典表示

- 特典カード: フェーズ・付与日・**有効期限（日付明記・例「2028-07-08 まで無償」）**・対象機能リスト・付与時人数スナップショット。
- 期限 90 日前から「更新は運営からのお知らせをお待ちください（自動更新はされません）」の注意行を表示（更新期待の混乱防止・B-2 運用と整合）。
- review 系情報は**表示しない**（03 §3）。

### B-3 シスアド ベータ特典管理

- タブ構成: 「付与一覧」（フィルタ: フェーズ/種別/review_flag）・「付与候補」（dry-run・02 §4.5）・「条件マスタ」（criteria CRUD）。
- 付与一覧の行操作: 取消（理由必須ダイアログ）・延長（月数入力）・審査解決/手動フラグ。review_flag 行は警告色ハイライト。
- 手動付与フォーム: grantKind/betaPhase/scope 選択＋`skipCriteriaCheck` トグル（ON 時は note 必須・警告表示）。

## 2. 通知文言（BE `messages*.properties`・6 言語）

| キー | ja 例 |
|---|---|
| `notification.beta_perk.granted.title` | ベータ特典が付与されました |
| `notification.beta_perk.granted.body.individual` | 日頃のご利用ありがとうございます。ベータ第{phase}期の特典として、対象機能をサービス提供期間中無償でご利用いただけます。 |
| `notification.beta_perk.granted.body.teamOrg` | ベータ第{phase}期の特典として、対象機能を{validUntil}まで無償でご利用いただけます（以後の更新は都度お知らせします）。 |
| `notification.beta_perk.revoked.title` | ベータ特典が取り消されました |
| `notification.beta_perk.revoked.body` | 利用規約に基づき、ベータ特典を取り消しました。詳細はお問い合わせください。 |
| `notification.beta_perk.extended.title` | ベータ特典の期間が延長されました |
| `notification.beta_perk.extended.body` | ベータ特典の無償期間を{validUntil}まで延長しました。 |
| `notification.beta_perk.review_flagged.operations` | （運営向け）ベータ特典 {grantId} に審査フラグが設定されました（理由: {reason}） |

- **「永久」を含む文言は禁止**（03 §8）。取消通知に検知手法の詳細を書かない（03 §3）。

## 3. i18n（`billing.json` の `betaPerks` セクション・6 言語）

- ファイルは F20.1 04 §3 で新設する `frontend/app/locales/{ja,en,zh,ko,es,de}/billing.json` に追記（nuxt.config `files` 登録は F20.1 側で実施済み前提・重複登録不要）。
- **`billing.json` はトップレベルを `billing` でラップする**（F20.1 04 §3 で確定）。よって `betaPerks` は **`billing.betaPerks`** の下に置き、参照は **`$t('billing.betaPerks.sectionTitle')`** となる（下記 JSON は billing ラップ内に追記する断片）。
- 直書き禁止・6 言語すべて追加（未翻訳は暫定 ja 同値可）。

## 4. FE 実装規約・手助け

- 型は生成型優先（BE マージ後 `npm run generate:types`）。`eligibility` の描画ゲート: データ到着まで skeleton（順序リストの描画ゲート・memory `feedback_async_ordered_list_gate_render`）。
- B-1/B-2 セクションと B-3 ページに `/手助け` 使い方ガイドを付与。カード内容: 「ベータ特典とは」「付与の条件（自動付与・申請不要）」「期間と更新（個人=サービス提供期間中/団体=2 年+都度更新）」「譲渡禁止と取消（規約）」の 4 カード。
- 新規ページ B-3 は `/統一`（PageHeader/SectionCard・戻るボタンは PageHeader 内蔵 opt-out 規約）。
