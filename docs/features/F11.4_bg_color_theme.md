# F11.4 背景色テーマ機能

## 機能概要

ライトモード時の背景色をユーザーが10色のプリセットから選択できる機能。
ダークモード時は選択色を無効化し、PrimeVue デフォルトの `bg-surface-ground` を使用する。

---

## 実装方針

| 要素 | 詳細 |
|---|---|
| CSS変数 | `--bg-color`（`documentElement` に設定） |
| 状態管理 | Pinia store（`useAppearanceStore`） |
| 永続化 | localStorage（プライマリ）+ `/api/v1/settings/appearance`（セカンダリ） |
| モード制御 | ライトモード時のみ `--bg-color` を適用。ダークモード切替時に変数を削除 |

## ダークモード用背景色 `darkBgColor`（2026-06-23 追加）

ライト用 `bgColor` と独立した `darkBgColor` フィールドを BE/DB に追加した。

### デフォルト値と方針

| フィールド | デフォルト | 用途 |
|---|---|---|
| `bgColor` | `#f3efe0` | ライトモード用背景色 |
| `darkBgColor` | `#18181b` | ダークモード用背景色（shadcn-ui zinc-950 相当） |

FE 側での `darkBgColor` プリセット UI は `BackgroundColorPicker.vue` にダーク系8色プリセットを追加することで実装した。
BE は既に `darkBgColor` を保存・返却できる状態になっている。

## ダークモード時の挙動

- `applyBgColor()` が呼ばれた際、`isDark === true` の場合は `--bg-color` CSS変数を `darkBgColor` の値で設定する
- これにより「ダーク時に `--bg-color` を削除するとボディが `#f3efe0`（クリーム色）に見えるバグ」を根治
- `applyTheme()` の末尾でも `applyBgColor()` を呼ぶことで、テーマ切替時に即座に背景色制御が反映される
- `BackgroundColorPicker.vue` は `isDark` フラグに応じてライト用10色 / ダーク用8色を切り替えて表示する

## 設定の永続化

1. **localStorage（プライマリ）**: `appearance` キーに JSON 形式で保存
2. **サーバー（セカンダリ）**: `/api/v1/settings/appearance` に非同期 PUT
   - 失敗してもサイレントフォールバック（localStorageが正として動作）

## BEサーバー保存（2026-06-20 実装）

FE の localStorage 保存（プライマリ）に加え、BE 側でもサーバー保存を実装した。
これにより複数端末・ブラウザをまたいで外観設定が同期される。

### API 仕様

| メソッド | パス | 認可 | 説明 |
|---|---|---|---|
| `GET` | `/api/v1/settings/appearance` | 認証必須 | 設定取得（未登録時はデフォルト値を返す・DB保存なし） |
| `PUT` | `/api/v1/settings/appearance` | 認証必須 | 設定保存（upsert・保存後の値を返す） |

### レスポンス形式

```json
{
  "data": {
    "theme": "LIGHT",
    "bgColor": "#f3efe0",
    "darkBgColor": "#18181b",
    "seasonalThemeId": null,
    "hideChatPreview": false
  }
}
```

### DB テーブル

テーブル名: `appearance_settings`（Flyway: `V122.001` で作成 / `V127.001` で `dark_bg_color` カラム追加）

| カラム | 型 | 説明 |
|---|---|---|
| `id` | `BINARY(16)` | UUIDv7（アーキ原則6準拠） |
| `user_id` | `BIGINT` | ユーザーID（FK なし・アーキ原則1準拠） |
| `theme` | `VARCHAR(8)` | テーマモード（`LIGHT` / `DARK`） |
| `bg_color` | `VARCHAR(32)` | ライトモード背景色 HEX コード |
| `dark_bg_color` | `VARCHAR(32)` | ダークモード背景色 HEX コード（デフォルト `#18181b`） |
| `seasonal_theme_id` | `BIGINT NULL` | 季節テーマ ID（null 許容） |
| `hide_chat_preview` | `BOOLEAN` | チャットプレビュー非表示フラグ |
| `created_at` / `updated_at` | `DATETIME(6)` | タイムスタンプ |

**設計原則の適用:**
- **原則6（UUIDv7）**: 新規テーブルのため UuidV7Entity 継承（`BINARY(16)` 主キー）
- **原則1（クロスドメイン FK 禁止）**: `user_id` への FK 制約なし・INDEX のみ
- **原則7（AbstractTenantAwareRepository 非該当）**: `organization_id` を持たない個人帰属データのため `JpaRepository` を直接継承
- **upsert**: `UNIQUE KEY uq_appearance_settings_user_id(user_id)` により 1 ユーザー 1 行を保証
- **IDOR 防止**: Controller は `userId` を URL/body から取らず `SecurityUtils.getCurrentUserId()` 由来のみ
