## 2. UX 要点

- **手数料の明示**（決済確認画面）：額面・2.5%上乗せ・支払総額・「返金時に手数料は戻りません」注意書き（F22.1 04_ui_i18n と統一文言）。
- **受取側の受取額表示**（受領者設定）：額面−2.5%の着金額。
- **後見切替のUX**：切替中はヘッダに「○○さん（お子さま）として操作中」バナーを常時表示し、誤操作を防ぐ。終了ボタンを常設。自立段階の子は一覧に「自立済み（切替できません）」と理由表示。段階ラベルは国別 `GuardianshipAgePolicy` の `stageKey`（`membership.guardianship.stage.*`）で引くため、対応国を増やすときは stage キーを追加するだけ（UIロジック不変）。
- **まとめ支払いのADHD配慮**（[[user_adhd_tendency]]）：未払いを一画面に集約、デフォルト全選択、ワンタップ決済。入力摩擦ゼロ。
- **継続課金のわかりやすい管理（2026-06-04）**：「今月スキップ／解約／再開」を明示ボタンで提供。**解約は「○月○日まで利用可」と日付を明記**（期末まで利用可・日割り返金なし）、**今月スキップは「○月分はお休み・次回課金日◯月◯日」**を明示。いずれも**次回課金日・利用期限を常時表示**＋確認ダイアログ（誤操作防止）。スキップ月は閲覧も延びない旨を案内（README §4.5）。

  - **FE 実装状況（2026-06-06・P5-FE 第三陣）**：`pages/me/payments/subscriptions.vue`（一覧・解約・今月スキップ・再開）＋ composable `useMembershipSubscriptionApi` ＋ 手書き型 `types/membershipSubscription.ts` ＋ i18n 6言語（`locales/{lang}/payment.json` の `payment.membership.subscription.*`）を実装済み。BE は PR #1366 main 済み。
  - **加入（subscribe）UI は次 PR に送る（本 PR 範囲外）**：会費加入は `POST /api/v1/me/payment-methods/setup-intent` → **Stripe.js（`@stripe/stripe-js`）で SetupIntent を `confirmSetup` し PaymentMethod を確定** → `POST …/confirm`（attach＋既定設定）→ `POST /api/v1/payment-items/{itemId}/subscribe` という多段フローであり、Stripe.js のクライアント統合（公開鍵設定・`Elements`/PaymentElement・3DS リダイレクト・CSP `script-src`/`frame-src` への `js.stripe.com`/`hooks.stripe.com` 追加）の設計確定が前提となる。中途半端な決済 UI を main に置くと PCI/3DS 経路の動作未検証のまま誤って加入導線が露出するリスクがあるため、**加入導線（subscribe ボタン／ページ）は payment_item 詳細側の責務として Stripe.js 統合設計と合わせて次 PR で実装する**。composable には `subscribe`/`createSetupIntent`/`confirmPaymentMethod` のラッパーを先行して用意済み（次 PR から即利用可）。
- **立替/精算のわかりやすさ（案3）**：チーム ADMIN が協会請求を立替えた一覧を「立替中（精算待ち）／精算済」で表示。精算確認は F04.9 確認必須通知から1タップ。領収書はチーム名義で表示。
- **ペイウォール導線**：ロック表示から購入→決済→即時解錠までを最短ステップ。
- **アクセシビリティ**：金額・期限は読み上げ対応、状態色（未払/支払済/期限切れ）に色以外の記号併用。

## 4. 型定義

- API レスポンス型は `frontend/app/types/generated/`（openapi-typescript 自動生成）を優先。Backend API 確定後に `npm run generate:types` で再生成。
- 手書き型は `frontend/app/types/payment/` に最小限（生成型へ段階移行）。`any` 禁止・複雑な型パズル禁止。
