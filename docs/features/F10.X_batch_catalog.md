# F10.X バッチカタログ

Mannschaft 内に存在する全バッチ（`@BatchEndpoint` 付与済み）の一覧。
本書は F10.X 第一陣（バッチ実機検証基盤）と第四陣（一斉付与）の成果物。

## 概要

- バッチ実機検証基盤: `com.mannschaft.app.admin.batch.BatchEndpoint` アノテーションで宣言し、`BatchEndpointRegistry` が起動時に走査・収集する。
- 全 `@Scheduled` 付きエントリポイント（運用バッチ）に `@BatchEndpoint` を付与する。
- 命名規約: `{domain}-{action}[-{cadence}]`（kebab-case）。重複は `BatchEndpointRegistry` が起動時 FAIL FAST。
- 除外: アプリ監視用の `HealthStatusListener.pollHealthStatus`（Spring Boot Actuator のヘルス状態ポーリング、運用実行用途なし）、ファサード経由のみで実体ではない `ScheduleMediaService.cleanupOrphanMedia` / 手動 API でのみ動かす `StoragePathMigrationBatchService` などは付与対象外。
