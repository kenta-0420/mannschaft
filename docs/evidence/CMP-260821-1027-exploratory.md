# 探索（アリシゼーション）CMP-260821-1027 — 存在オラクルの本文正規化

実施 2026-11-04（原記録は足軽4）、裏取り 2026-11-05（verify-B）。住民ペルソナ（高齢・低リテラシー）で、備品とコルクボードを所属者・非所属者に分けて URL 直打ちと画面操作で触った。求人・マッチ・フレンドの探索は本回では未実施。

## 本戦役の目的に関わる観測
- 非所属者が他チーム・不在スラッグの備品ページを開くと、画面は同一文言「備品がありません」で、実在と不在の差は画面に出ない。備品詳細 GET は実在でも 404 EQUIPMENT_001 で不在と一致した（裁定どおり）。

## 判定
### 既存の欠陥で起票済み（本戦役の射程外）
- E1: 備品一覧の品物を押しても何も起きない（親ページが select を受けていない）。借りる・返す・履歴の画面が無い。2026-03 の初期実装からの欠落。
- E2: 借りた本人の MEMBER が自分の貸出分を返却できず 403 COMMON_002（仕様 F07.3 の「MEMBER は自分の貸出分の返却」に反する認可の仕様違反）。認可根治 Wave2（2026-07）の過剰な絞り込みが原因で、1027 の変更ではない。
- 上記2件は CMP-261105-0349 で起票済み。

### 棄却
- E6: 一覧 GET が他チームで 403 COMMON_002、不在スラッグで 404 COMMON_005 となる差は、F07.3 の「404統一は詳細 GET だけ」の裁定と、チームスラッグの実在は非機密という既存裁定のとおり。仕様どおり。
- E3（備品側）: 備品メニューが出ないのは、検証チームで備品モジュールが未有効だったテスト構成による環境起因。
- 備品返却で非所属者に 403/404 の差が残る件は、実機E2Eで殿が範囲外と裁定した D-1027-1 の再観測であり、新たな欠陥ではない。

### 本戦役が是正した確定不具合
- なし。

## 気づきで判定が付いていないもの（起票なし）
- 備品一覧 API の equipmentName が null、FE の備品 API ラッパーと BE の必須項目の不一致（導線を付けると表面化する latent）。CMP-261105-0349 で E1 の画面を作る際に確認が要る。
- 所属者の備品ページで GET trending が 403 となりコンソールに赤エラーが出る。画面は無症状。
