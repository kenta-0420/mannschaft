# 実機E2E CMP-260826-1455（BAN された村長・長老の権限操作 / 実装PR #4244）— 合格

実施 2026-11-03。BE 8081、FE 3001。テスト専用の村（COMMUNITY）と、接頭辞 `e2e1103` のアカウントを用いた。資格情報は本書に記載しない。

本体の修正（BAN 済みを除外する正準述語 `findActiveByVillageIdAndSubject` への切替）は PR #3572（2026-10-11 merge）で着地済みで、#4244 は村ドメイン全域に同種の誤用が残らないことを固定する番人テスト（`VillageModeratorPredicateWideGuardArchTest`）を加えた PR である。本実機は main 上の挙動で確認した。

## 役割
- 村長（BAN される側）、別の村長（BAN する側）、長老（BAN される側）、村人、非村人。
- 手順: 村長が村を作成 → 別の村長・長老・村人が参加 → ロールを昇格 → 別の村長が元の村長と長老を BAN。

## 実測（API）
- BAN 前の正の対照: 長老は calendar-events・festivals・invitations・join-requests が成功し、changeRole と ban は 403 VILLAGE_024。村長は calendar-event 作成と changeRole が成功。
- BAN 後: BAN 済みの村長と BAN 済みの長老が、calendar-events・festivals・invitations の作成、join-requests の閲覧、changeRole（他人・同格）、ban（他人・同格）の 8 操作を行うと、2者 × 8 操作 = 16 件すべて 403 VILLAGE_024。DB に BAN 者名義の行は作られず、他の村長・村人のロールは不変。
- 非村人・村人の視点でも同じ操作は 403（負の視点）。
- BAN 済みの村長が再参加（自由参加・招待受諾）を試みると 403 VILLAGE_031「この村から BAN されています」。

## 実測（画面）
- 別の村長（権限あり）: 村人一覧に「ロール変更」「BANする」、運営メニューが出る。
- BAN 済みの村長・長老: 村人一覧は API が 404 のため「村人がいません」、操作ボタンなし。`/villages/{id}/admin` を URL 直打ちすると「この画面は村長・長老のみ利用できます」。村人・非村人も同様。

合格。BAN された村長・長老は、権限操作を 16/16 件で拒否された。
