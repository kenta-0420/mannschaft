# 探索（アリシゼーション）CMP-260822-1730 — チームTZ対応・日跨ぎ予約枠

実施 2026-11-04（原記録は足軽2、住民・スマホ片手×時間破壊）、裏取り 2026-11-05（verify-A）。スマホ幅（390・360）で、予約と「自分の予約」を指で触り、タイムゾーンを Asia/Tokyo と America/New_York で比べた。

## 本戦役の目的に関わる観測
- 360 幅・America/New_York で、枠の時刻に9時間・1日のずれは無かった。日跨ぎ枠（11/3 23:00 → 11/4 01:00）が「自分の予約」に「2026-11-03 23:00:00 - 01:00:00」と終了日なしで出て、終了が翌日であることが判別できなかった（R3）。

## 判定
### 本戦役が是正した確定不具合
- R3: 日跨ぎ枠の「自分の予約」一覧が終了日を出さない。`ReservationList.vue` が `slotDate` と `endTime` だけを使い、API が返す `endDate` を見ていない。#2922 が `end_date` を導入したのに、本人予約一覧が追従していなかった。是正は PR #4296（既存の「翌 HH:mm」表記を流用）。回帰テストは `ReservationMapperTest`（red はコンパイルエラー）と `ReservationList.spec.ts`。red と green は同名 JSON の `regressions` に記録した。

### 既存の欠陥で起票済み（本戦役の射程外）
- R2: 390・360 幅で「自分の予約」の DataTable の列が固定 px（計570px）でスクロール枠が無く、ステータスと取消ボタンが縦に折り返し、360 では取消ボタンが画面外に出る。2026-03 の初版からの欠陥。CMP-261105-0345 で起票済み。

### 棄却
- なし。

## 気づきで判定が付いていないもの（起票なし）
- 「自分の予約」の時刻表記が `HH:MM:SS` で、並びが日付順でない。R3 の是正は終了日の表示に限り、この点は変えていない。
- 上部タブの右切れ、「週」ラベルの縦折返し（390 幅）。
