既存 Mapper を5 Serviceから再利用し、Controllerの変換を Service 内へ移す最小案とする。KbSearchController の画像URL変換には Mapper を残す。Entityを返す private/package-private helperは内部利用のまま維持する。HTTP DTOのapi移動、Mapper全面刷新、ID/DDL変更、新規汎用モデルは対象外。

変更系および `getPage` の閲覧数加算では、最終変更の flush 後に DTO 化する。候補は既存 `save` を維持し必要な最終地点へ `Repository.flush()` を追加する方式。create の path 再設定、update、publish、archive、restore、template update、閲覧数加算を対象にし、作成時の永続値も確定させる。冪等な no-op 枝へ不要な flush を増やさない。flush 例外は既存 tx を rollback させ、成功応答で隠さない。
