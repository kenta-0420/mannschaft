# 実機E2E CMP-260824-2217（実装PR #2934 予約マトリックスの本人予約済み表示・待機登録 409）— 合格

実施 2026-11-03。BE 8081（origin/main の bootJar）、FE 3001。チームは接頭辞 `e2e1103` の予約モジュール有効チーム（ライン1本）と、他テナントのチーム1つ。資格情報は本書に記載しない。

## 役割
- チーム ADMIN（ra）、MEMBER 2名（rm1・rm2）、無所属（rout）、他テナント ADMIN（rb）、未認証。
- 枠（2026-11-05）4本（定員1・1・2・1）。予約は rm1 が複数枠、ra が1枠、rm2 が MANUAL 承認枠で PENDING。待機は rm2・rm1 が満席枠へ登録。

## 実測（API: グリッド `/teams/{slug}/reservation-slots/grid`）
- rm1: 本人予約の2枠が BOOKED かつ reservedByCurrentUser=true、取消した枠は AVAILABLE・false。from/to のレンジ指定でも同じ。
- rm2（予約なし）: BOOKED の枠も含め全セル false。ra は本人の枠だけ true。レスポンスに他人のユーザー ID・氏名は含まれない（生 JSON を走査して該当ゼロ）。
- PENDING: rm2 が MANUAL 枠を予約すると status=PENDING で、rm2 のグリッドは true、rm1 は false。取消後は false に戻る。
- 待機登録: 予約者本人（CONFIRMED・PENDING とも）は 409 RESERVATION_013。他人の満席枠への登録は 201。重複登録は 409 RESERVATION_047。
- 権限横断: 非メンバー・他テナント ADMIN はグリッドも待機登録も 403 RESERVATION_021。未認証は 401。

## 実測（画面）
- rm1: 本人予約の2枠が「予約済み」で disabled、空き枠は押せる。
- rm2: 待機登録済みの枠が「待機中」（押すと取消）。「予約済み」は出ない。
- ra: 他人で埋まった枠は「埋まっている」（押せる＝待機登録導線）、本人の枠は「予約済み」disabled。
- rout: 「権限がない場合は表示できないことがあります」の案内画面（403 を握りつぶさない）。

## 欠陥（軽微・アクセシビリティ）
- D-2217-1: 本人予約済みセル（disabled）の aria-label が「予約済み: 押すとキャンセル待ちに登録できます」のまま残り、実際は押せず登録もできない。スクリーンリーダーに誤誘導する。原因は `SlotMatrixPicker.vue` の `waitlistAriaHint` が `reservedByCurrentUser` を見ないこと。実機の判定は合格（AC は満たす）で、本欠陥は別途是正した（回帰 R1、PR #4293）。
