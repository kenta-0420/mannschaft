# CMP-261004-1942 / 1943 アリシゼーション記録（2026-10-10）

実機E2E の後に、住民4体（sonnet）を目的だけ与えて実画面（FE 3006 / BE 8086）へ放ち、殿が裏取りした。

## 配役

| 住民 | 人格 | 攻め口 | 目的 |
|---|---|---|---|
| 1 | 高齢の管理者 | 素直 | 限定公開のチーム・組織を作り、後で公開範囲とサポーター受け入れを変える |
| 2 | 英語・ドイツ語のスマホ利用者（390x844・360x800） | 表示崩れ・連打 | 応援・解除でヘッダの人数が変わるかを見る |
| 3 | 部外者 | 隙間狙い | PRIVATE 組織・制限チームを直打ちして中身と応援に辿り着く |
| 4 | 部外者 | 素直 | 「サポーター以上」のチームのサポーターになる |

## 本戦役の確認

- 応援→人数 +1→解除→元に戻る、をチーム（`f0810-go-team`）・組織（`f0810-multisport-club`）とも en の実画面で確認した。2回連打でも二重送信なし。390/360 幅でページの横はみ出しなし、人数表示の切れなし。
- 非所属者は閲覧不可の団体で名前・人数・本文を一切見られない（画面・HTML・title とも）。

## 棄却

- `/follow/status`・slug-resolve で団体の実在が分かる: 実在は設計上秘匿の対象外（F01.2/04 §49）。名前・人数は漏れない。
- UI ログインで /login を抜けない: 2条件で再試行し再現せず（dev 初回ビルド中の水和前入力）。
- 言語を de に保存しても英語のまま: 製品では保存・遷移・リロードとも de を保持。テスト補助 `loginViaApi` が locale を書かないための見かけ。
- 応援ボタンの高さ 35px: 44px は一部機能の個別要件で全体規約ではない。
