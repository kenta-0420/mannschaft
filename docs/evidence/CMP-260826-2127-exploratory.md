## 本戦役の目的に関わる観測
- MEMBER の画面・API で、DRAFT と未公開 ARCHIVED のタイトル・期間・ステータス・メンバー名は確認されなかった（詳細・枠・PDF は 404）。COLLECTING・ADJUSTING の割当は伏せられ、MEMBER は未割当扱いになった。

## 判定
### 既存の欠陥で起票済み（本戦役の射程外）
- S1: 確定済み（PUBLISHED・ARCHIVED）のシフト表への変更依頼が 3 種とも失敗（400・409 SHIFT_012）し、理由の案内が無い。BE の 409 は仕様どおりで、FE が追随していない。導線も弱い（`/my/shifts` の「変更を依頼する」が詳細に飛ぶ）。
- S2: MEMBER に「編集」タブ、board の作成・削除・D&D・未割当プールが出る。API は 403 で防御済みで、UI が見せすぎている。
- S4: SUPPORTER が `/shift/{id}` を開いて 403 になると、本文が空白でエラー表示も戻る導線も無い。
- 上記3件は CMP-261105-0348 で起票済み。

### 殿の裁定により既存の戦役へ畳み込み
- 下書き 434 の board と change-requests が 404 にならず、MEMBER 本人が出した依頼 1 件が見える（O-2127-4 の再観測）。裏取りでは、他者の依頼・氏名は出ず、残るのは「下書きの ID が存在する」という 1 ビットのみと確認した。殿の裁定により、既存の CMP-260903-0654 へ畳み込む（台帳の注記は別 PR）。

### 棄却（仕様どおり）
