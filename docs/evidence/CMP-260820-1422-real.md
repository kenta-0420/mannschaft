# 実機E2E CMP-260820-1422（実装PR #4246 コルクボードの存在オラクル一掃）— 合格

実施 2026-11-03。BE 8081（origin/main の bootJar を WSL の Linux JVM で起動）、FE 3001、共有DB 3306（Flyway V255）。
データは接頭辞 `e2e1103` のテスト専用アカウントで作成した。個々の資格情報は本書に記載しない。

## 役割（ID またはロール名で表す）
- チーム ADMIN（cadm）、チーム MEMBER（cmem）、非メンバー（cout）、他チーム／他組織の ADMIN（coth）、未認証。
- ボードは チームボード・個人ボード・組織ボードの3種を用意し、存在しない ID（9000000000）と比較した。

## 期待
非閲覧者が越境したとき、および存在しない ID のとき、status・error.code・message が一致する（404 CORKBOARD_001）。閲覧者（メンバー）には権限不足 403 CORKBOARD_009 が残る。

## 実測（API 直叩き。実 JWT・モックなし）
| 役 | 操作 | 実在ボード | 不在ボード |
|---|---|---|---|
| 非メンバー | チームボードの GET/PUT/DELETE、boardId 単独の GET、カード作成、セクション作成 | 404 CORKBOARD_001 | 404 CORKBOARD_001（本文まで完全一致） |
| 他チーム ADMIN | 同上、他人の個人ボード | 404 CORKBOARD_001 | 同左 |
| 非メンバー・ADMIN | 組織ボード（組織パス・boardId 単独・カード作成） | 404 CORKBOARD_001 | 同左 |
| 他チーム ADMIN | 自チーム経路で他チームのボードを指定（越境パス） | 404 CORKBOARD_001 | - |
| MEMBER | 詳細 GET | 200 | 404 |
| MEMBER | PUT/DELETE/カード作成/セクション作成 | 403 CORKBOARD_009（診断は維持） | - |
| チーム ADMIN | GET・カード作成・セクション作成 | 200 / 201 / 201（正の対照） | - |
| 未認証 | GET | 401 | 401 |

拒否後の DB は、ボードの version・deleted_at が不変で、カード・セクション件数も不変だった。

## 実測（画面。実ブラウザでログイン後に URL 直打ち）
- 非メンバー・他チーム ADMIN: 実在 ID も不在 ID も同一の「ボードの取得に失敗しました／再試行」。API は 404。
- MEMBER: ボードを表示。「新規カード」ボタンは出ない。
- チーム ADMIN: ボードを表示し「新規カード」が出る。

## 合否
AC1（非メンバーの本文一致）・AC2（組織ボード・boardId 単独・カード/セクション）・AC3（メンバーの 403 維持）を実機で確認した。合格、欠陥なし。
