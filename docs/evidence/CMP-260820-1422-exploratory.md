# 探索（アリシゼーション）CMP-260820-1422 — コルクボードの存在オラクル

実施 2026-11-04。住民ペルソナ（高齢・低リテラシー、チーム MEMBER と非所属者を別ブラウザ文脈に分離）で、コルクボードを URL 直打ちと画面操作で触った。観測の原記録は足軽4。裏取りは 2026-11-05。

## 本戦役の目的に関わる観測
- 非所属者が、実在ボード・不在ボード・他チームのボード・組織ボード・不在スラッグ配下のいずれを開いても、画面は同一の「ボードの取得に失敗しました」で、API も全パターン 404 CORKBOARD_001 だった。実在と不在の差は画面にも API にも出ていない。存在オラクルの是正は住民の目でも成立している。

## 判定
### 既存の欠陥で起票済み（本戦役の射程外）
- チームと組織のサイドバー・ナビにコルクボードへの項目が無く、URL 直打ちでしか辿り着けない（E3）。`/corkboard` の「ボードを作成」が無反応で、所属チームの共有ボードが一覧に出ない（E4）。いずれも 1027/1422 の変更ではなく、2026-05 の初期実装からの欠落。CMP-261105-0350 で起票済み。

### 棄却（仕様どおり）
- MEMBER に新規カードの追加手段が無い（E5）。`docs/features/F09.8_corkboard.md` の既定が ADMIN_ONLY で、閲覧のみが仕様。空ボードに「管理者に頼む」案内が無いのは UX 面の指摘にとどまる。
- 失敗画面が「取得に失敗しました」と「再試行」だけで、権限なし・不在を言い分けない点は、存在秘匿のために両者を同一応答にするという本戦役の意図そのものであり、欠陥としない。

### 本戦役が是正した確定不具合
- なし。

## 後始末
コルクボード・カードは探索で新規作成していない（作成ボタンが無反応のため）。DB の直接操作は行っていない。
