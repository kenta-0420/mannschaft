## 実機E2E（ロール横断・URL直打ち）
- 組織 71 に委員会を作成（API は前提）し、委員長（アバター有）と委員（アバター無）を配置した。
- API: 一覧 200。各メンバーに displayName が付き、avatarUrl は委員長のみ有りで委員は null。
- 委員長の画面 /committees/{id}: 名前（ID ではない）とアバター画像が 1 つ表示される。委員の画面も名前が表示される。
- 非委員（同組織の一般メンバー）: メンバー一覧 API・詳細 API とも 403。画面に氏名は出ない。
- 他テナント: 一覧・詳細とも 403。URL 直打ちでも氏名は出ない。
- 後始末: 委員会・委員行・追加した組織ロール行を削除し、元の状態に戻した。
