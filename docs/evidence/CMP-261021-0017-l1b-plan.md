## shard と CI の維持契約

- `ShardAssignment` は `backend/build.gradle.kts:230-326`。重み降順の安定LPT、最小合計の先頭shardへ割当。同重みの順序・同累計時の先頭優先も維持する。
- 未計測・ファイル欠損は unsigned 32bit 化した Java String.hashCode の剰余でfallback。負hash/Int.MIN_VALUEでも同じ値を返す。ネストは `$` 前のFQCNに束ねる。
- `loadWeights` は空行/コメント/区切りなし/数値変換不能を読み飛ばす。Map入力順序や重複キーの現行結果を変えない。validationの強化はこの移設に混ぜない。
- migration除外は「.migration.配下 AND 単純名Flyway」のみ。除外時はLPT入力から先に取り除く。実行filterとcoverage guardが同じ述語を直接呼ぶ構造を維持 (`:590-710`)。
- test側はtotal/index両方が数値かつtotal>1の時だけ分割、範囲外indexはfail。未指定/非数値/total<=1は現行通り分割しない。verify側はtotal<=1でfail。両者の差も勝手に統一しない。
