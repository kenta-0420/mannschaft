# 探索（アリシゼーション）CMP-260822-1243 — 退会時の個人設定の消去

実施 2026-11-04（原記録は足軽5、ADHD 傾向×中断放棄）、裏取り 2026-11-05（verify-A）。設定変更 → 退会の中断（4通り）→ 退会完了 → 取消 → 取消後の個人設定、の順に画面で触った。途中、確認メールが届かずログインできない環境起因の停止があり、殿が対象ユーザーを有効化して再開した。

## 本戦役の目的に関わる観測
- 退会の中断（ダイアログを Esc で閉じる、戻る、別タブ、タブを閉じて開き直す）はいずれも安全に元へ戻り、設定は退会前の値のまま保持された。退会完了後に再ログインすると退会は自動取消され、通知設定は変更値のまま残った。

## 判定
### 既存の欠陥で起票済み（本戦役の射程外）
- W1: 退会ダイアログの削除ボタンのダブルクリックで `DELETE /users/me` が2回飛ぶ（1発目は 200、2発目は空パスワードで 400 AUTH_010）。`SettingsDeletionPreviewDialog.vue` と `account.vue` に二重送信ガードが無い。アカウント削除フロー初版からの欠落。
- W2: 説明「この操作は取り消せません」と実際の挙動（30日以内の再ログインで自動取消）が食い違い、復帰できない項目（push・Google Calendar・天気地点・お気に入り）の案内も無い。
- 上記2件は CMP-261105-0346 で起票済み。
- W4: メール未確認でログインして AUTH_002 になっても、ログイン画面から確認メールの再送に進めない（再送は登録直後の `/verify-email` のみ）。CMP-261105-0347 で起票済み。

### 棄却
- W3: `/settings/account` 表示時の `GET /account/data-export/status` の 404 は、エクスポート未作成（GDPR_003）の正常表現で、画面は正常。設計どおり。
- W5: 登録時にハイドレーション完了前にチェックを入れると、利用規約のチェックだけが外れる。dev サーバーの SSR 初回描画の遅延による環境起因（本番では窓が極小）。

### 本戦役が是正した確定不具合
- なし。

## 気づきで判定が付いていないもの（起票なし）
- ローカル環境ではメールが DEAD_LETTER になり、画面だけでメール確認を完了できない。環境起因で、本番相当ではない。
