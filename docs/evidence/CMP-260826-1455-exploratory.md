# 探索（アリシゼーション）CMP-260826-1455 — BAN された村長・長老の権限操作

実施 2026-11-04（原記録は足軽1、住民・一般×連打）、裏取り 2026-11-05（verify-A）。村長が村人を BAN する場面と、BAN された人が村へ戻ろうとする場面を、画面で連打を交えて触った。村の探索は戦役 CMP-260827-1808 の観測と同じ住民の記録で、起票は 1808 の発見元として行われている。

## 本戦役の目的に関わる観測
- BAN された人が自由参加村で「参加する」を3連打すると、POST は 403 が3回返り、BAN は維持された。BAN された人が権限操作に入り込む経路は見つからなかった。

## 判定
### 既存の欠陥で起票済み（本戦役の射程外）
- V3b: BAN の解除導線が無い。BE に unban API が存在せず、BAN 済みの人が一覧に出ない。F17.1 の設計上 BAN は一方向で、1808 が BAN 後の再参加を遮断して永久 BAN が顕在化した。CMP-261105-0343 で起票済み。
- V2: 「参加する」の連打で POST が押下回数ぶん飛び、409・403 のトーストが積み重なる。CMP-261105-0343 で起票済み。
- V1: 100村到達ユーザーの参加で 429 に対し、共通の「操作が集中」トーストと固有エラーの二重表示。非村人が村を開くと掲示板の 403 が「取得に失敗しました」の赤トーストになる。CMP-261105-0343 で起票済み。
- V5: 村人数が3箇所（ヘッダー・ヒント・一覧）で不一致。`member_count_cache` が作成時にしか書かれない。CMP-261105-0344 で起票済み。

### 棄却
- 「確認ダイアログなしで即 BAN される」は再現しなかった。BAN は理由欄付きの確認ダイアログを通る。住民の自動操作がダイアログの確定ボタンまで連打して通過していた。

### 本戦役が是正した確定不具合
- なし。

## 気づきで判定が付いていないもの（起票なし）
- 村長の村人一覧が「#990950」のような ID 表記のみで氏名が出ず、列見出し（村名・種別・作成日）が村人一覧にそぐわない。裏取りの対象外で、起票していない。

## 後始末
探索で BAN された非村人 1 名（接頭辞 e2e1103、作成元は本探索）は、解除導線が無く、DB の直接操作を行わない方針のため残置している。ほかに新規データは作っていない。
