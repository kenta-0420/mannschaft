# 探索（アリシゼーション）CMP-260824-2217 — 予約マトリックス（本人予約済み表示）

実施 2026-11-04（原記録は足軽2、住民・スマホ片手×時間破壊）、裏取り 2026-11-05（verify-A）。スマホ幅（390・360）で、予約、取消、キャンセル待ちの登録と取消を指でタップして触り、タイムゾーンも切り替えた。

## 本戦役の目的に関わる観測
- 本人予約済みセルは disabled で、タップしても新規予約もキャンセル待ちも起きない（想定どおり）。本人が新規に予約した枠も同じ状態に変わった。
- 画面の挙動と読み上げ文言のずれを実測で再現した（R1）。

## 判定
### 本戦役が是正した確定不具合
- R1（旧称 D-2217-1）: 本人予約済み（disabled）セルの aria-label が「予約済み: 押すとキャンセル待ちに登録できます」で、押せない実動作と食い違う。`SlotMatrixPicker.vue` の `waitlistAriaHint` が `reservedByCurrentUser` を見ない。#2934 が `reservedByCurrentUser` を導入したが aria ヒントを追従していなかった。是正は PR #4293（回帰テストは `SlotMatrixPicker.spec.ts`）。回帰の red と green は本書の同名 JSON の `regressions` に記録した。

### 既存の欠陥で起票済み
- なし。同じ住民の記録にあった「自分の予約」のモバイル幅での崩れ（R2）は CMP-260822-1730 の探索に属し、CMP-261105-0345 で起票済み。

### 棄却
- なし。

## 気づきで判定が付いていないもの（起票なし）
- 自分のキャンセル待ち登録が「自分の予約」に残っているのに、マトリックスの当該枠が「空き」のままになる表示整合（要確認）。
- 予約作成の成功トーストが観測できない。予約後に出る閉じるボタンが 18x18 で 44px 未満。
- 新規チーム直後の ADMIN に出る「メンバーの権限を初期設定」モーダルが Escape で閉じず、画面を塞ぐ。既知の挙動の可能性。
- 予約をユーザー側からキャンセルすると、締切超過で 400 RESERVATION_026 になる（画面は親切な案内を出す。仕様どおりの動作）。
