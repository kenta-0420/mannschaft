# CMP-260910-0044 完了証拠: 監査ログのアーカイブ基準を UTC に統一

## 概要
- 実装PR: #3816（head 01c1dcf0b2、マージ済み）。レビュー: Codex 検分合格。
- 実機・アリシゼーション: 結果は pass（再実施分）。
- 環境: 監査ログのアーカイブは共有DBのパーティションを DROP するバッチのため、共有環境を避けた。使い捨ての MySQL と MinIO を立て、専用の BE で実施した。

## 実機E2E（UTC 境界・ロール横断）
- UTC 境界: 閾値の前後、および UTC 月初をまたぐ行（JST では翌月になる行）を用意し、バッチを実行した。閾値より古い行だけがアーカイブされ、境界より新しい行は本表に残ることを確認した。月の判定とパーティション DROP も UTC の月で行われた。
- ロール横断: 権限あり（SYSTEM_ADMIN によるバッチ起動）は実行できた。権限なしの一般メンバー・他テナントのロールは 403 となり、URL 直打ちでも監査ログの閲覧・バッチ起動に到達できないことを確認した。

## アリシゼーション
- 住民として画面を触り回った結果、新規の所見が4件あり、台帳へ別行で起票した（いずれも本行の実装範囲外）。
  - CMP-261020-1528: 監査ログ画面で日時が9時間ずれる（API が UTC の値に `+09:00` を付けて返す）。
  - CMP-261020-1529: 403 の監査ログ画面が権限不足ではなく「ログがありません」と表示される。
  - CMP-261020-1530: LOGIN_SUCCESS の監査行で `ip_address` と `user_agent` が入れ替わる（`LoginSuccessEvent` の引数順の食い違い）。
  - CMP-261020-1531: 権限のない一般メンバーにもチームの全メニューが見える。

## 既知の別件
- アーカイブ JSON の `created_at` が JST の壁時計のままになっている件は、既知の別件 CMP-261012-2344 であり、本行では扱わない。
