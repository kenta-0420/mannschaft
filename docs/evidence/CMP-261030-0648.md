# CMP-261030-0648 実機E2E・アリシゼーション記録

実装 PR: #4457（本体）、#4466（仮押さえ失効 PendingExpire）

## 実機E2E
- ADMIN が受け取る予約通知から `/teams/{slug}/reservations` に着く。
- 問い合わせ通知から `/teams/{slug}/chat?channel={id}` に着き、チャンネルが選択状態になる。業務アラートのボタンも同じ遷移先。
- PendingExpire は失効バッチを実行すると、通知の遷移先が slug の URL になる。
- MEMBER と部外者が URL を直打ちしても、他チームの情報は漏れない。
- 未実施: 承認待ち予約（MANUAL）の通知。承認制の枠を用意できなかった。

## アリシゼーション
- 実施。派生した欠陥は別行で起票した（管理者が非メンバーの問い合わせチャンネルの通知から着けない件、問い合わせチャンネルを設定する画面が無い件）。
