# CMP-261018-2311: 本番FEコンテナのヘルスチェック

Issue #3988 の原因は、IPv4のみの待受 `HOST=0.0.0.0` と `localhost` のIPv6優先解決の不一致だった。health URLを `http://127.0.0.1:3000/` へ合わせ、待受・ポート・health時間設定を維持した。

Frontend CIは既存のmain push限定方針を保つ。公開HTTPを60秒の期限で待った後、running/healthyを180秒の期限で待ち、最後に公開HTTPを再確認する。unhealthy・非running・health欠損・inspect失敗・期限超過は失敗し、Stateとlogsを常時出力して所有コンテナを撤去する。期限直前に残り秒数が0となる経路も防いだ。
