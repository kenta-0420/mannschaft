## 受け入れ条件と結果
| 条件 | 手順（UI） | 結果（実値） |
|---|---|---|
| UI 経由のアーカイブで ShiftArchivedEvent が出て PLANNED 消化が取り消される | 組織 ADMIN で /shift/1 の「確定公開」後、「アーカイブ」をクリック（transition?status=ARCHIVED が 200） | 約8秒後に消化2件とも CANCELLED（取消理由 SHIFT_DELETED）。割当の消化額 21,600 から 0。スケジュールは ARCHIVED |
| 対照: PLANNED が残る間は割当削除が 409 | 割当管理画面で削除 | 409。画面は「割当の削除に失敗しました」 |
| 取消後は割当削除が正常 | 同画面で再度削除 | 204、一覧から消え、DB の deleted_at が設定される |
| 付随（API）論理削除 | スケジュール DELETE | 204。消化 CANCELLED、消化額 21,600 から 0 |
| 付随（API）公開取消 | PUBLISHED から ADJUSTING | 消化 CANCELLED、消化額 0。再公開で新規 PLANNED（21,600）に積み直し |
