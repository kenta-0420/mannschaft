マスター（ユーザー）の判断・手作業・承認が要るため、殿や足軽だけでは先へ進めない事項の一覧。

台帳 [`docs/task-list.md`](task-list.md) は戦役単位の正本である。ここはその中で「マスター待ち」になっている個々の問いを、何をすれば解消するかまで具体的に並べる場所とする。

## 運用

- 新規は「未回答」節の末尾に追加する。ID は `MC-YYMMDD-HHMM`（JST、`date '+%y%m%d-%H%M'` で生成）。
- 解決したら状態を「解決済み（日付・回答）」に書き換え、下の「解決済み」節へ移す（消さない）。
- 各項目は ID / 起票日 / 関連、決まらないと進めない事、マスターへのお願い（選択肢と殿の推奨）、回答後に殿がやること、状態を書く。
